# vanity rules and systems to build

# rules
- crystal critters are an island type that gives out a loot table of stuff, which will always include a crate.
-- there are 3 sizes of each of these critters, and does have a primaryElement too
- crates are Packs
-- crates have a primaryElement and rarity
-- blueprints in inventory can be applied in a 2D UI to unlock stuff with gnomes

# implemented rules
- there is a new item type called key, mergeable up to level 5
- there is a new item type Blueprint
- there are other islands in the world with chests
- chests have a sign saying what level key to open it
- equip a key to show a prompt on a chest
- opening a chest rolls a loot table and gives the player a bunch of stuff
